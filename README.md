# MonoMarket - C2C Used Goods E-Commerce Platform

MonoMarket is a specialized consumer-to-consumer (C2C) e-commerce platform designed for the unique used goods market, heavily inspired by the operational models of leading Japanese recommerce giants such as Book Off and Mercari.

The project focuses on solving the core challenges of the second-hand industry: condition-based dynamic pricing, single-item unique inventory management, and real-time multi-language localization (i18n) for global markets.

---

## 🛠️ Tech Stack

- **Backend:** Java 21, Spring Boot 4.1.x, Spring Data JPA
- **Frontend Rendering:** Thymeleaf, HTML5, CSS3, JavaScript (ES6)
- **Database:** PostgreSQL 18+ (Dynamic attributes optimization via `JSONB`)
- **Dependency Management:** Maven
- **Internationalization:** Spring Boot i18n (English / 日本語)
